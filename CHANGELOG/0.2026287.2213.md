## Summary

**A rename in the other direction: the contract's knob is `stage_parallelism`, and the SDK helper that resolves it was still spelled for the retired engine.**

The contract half landed as `spec` `4e61d3d` (`podman_jobs` → `stage_parallelism`), and its migration entry landed in `plugin-migrate`. **This is the name that mirrored it and was missed:**

| before | after |
|---|---|
| `ResolvePodmanJobs` | `ResolveStageParallelism` |
| `PodmanJobsCapFallback` | `StageParallelismCapFallback` |

The doc is rewritten to the names that **exist** and to what the value now **drives**: it was `podman build --jobs N` (the concurrent stages of one build) and it is now the BuildKit daemon's `[worker.oci] max-parallelism` — the same "limit the number of parallel build steps that can run at the same time", applied when the daemon starts rather than per build. The cap's provenance is kept (it came from the podman-5.7.x blob-reuse SIGABRT race) but no longer as a live claim about a flag.

Two stale references in the same test file are swept with it: the config key it names (`defaults.podman_jobs_cap`) and the dead path in its provenance note (`charly/build_jobs_test.go`, which no longer exists — the note now marks it as the **former** home).

**⚑ Why this lands BEFORE leg 4** (the only breaking caller is `plugin-build/candy/plugin-build/resolve.go:252`, which is leg 4's own line): leg 4 would otherwise ship a call site spelled for the retired engine — a **tenth name for the same knob** in a diff that is otherwise honest about nine migrated ones. A rename that leaves a helper spelled for the retired engine is resolved-but-dead in the other direction.

**⚑ And the generalisable half — why the original sweep missed it.** That sweep was **claim-keyed on the contract's identifiers** (`BuildEngine`, `build_engine`, `CHARLY_BUILD_ENGINE`, `engine.build`, `podman_jobs`) and this is an **SDK function that mirrors the same knob**, in a repo those legs never swept for it. The discipline that catches it is **knob-keyed, not name-keyed**: search for the knob itself *and every name derived from it*, across every module the contract touches. That is "the authority is the artefact, not a summary of it" applied to the **surface** of a change rather than to its gate — and it is the third time in this programme that a control derived from the plan rather than from the tree was the defect.

Changed: **2 files, +32/−22** — `buildkit/build_helpers.go` (both symbols + the doc) and `buildkit/build_helpers_test.go` (the renamed test and its two swept references). One commit.
