# 2026.210.0910 — Drop targetkit/sshx/proclifecycle/testkit; consume the spec fabric slices (#55 STEP 1, sdk leg)

STEP 1 of the everything-is-a-plugin import-purity plan moved the standalone
fabric primitives into granular `github.com/opencharly/spec` sub-packages
(producer PR). This sdk leg DELETES the four now-relocated kits and repoints
every sdk consumer at the spec slices — a hard cutover, no alias shims.

Deleted (moved to spec):

- `sdk/targetkit/` → `github.com/opencharly/spec/transport`.
- `sdk/sshx/` → `github.com/opencharly/spec/sshx`.
- `sdk/proclifecycle/` → `github.com/opencharly/spec/proc`.
- `sdk/testkit/` → `github.com/opencharly/spec/testkit`.

Moved out of `sdk/kit`:

- `sdk/kit/process.go`'s launch helpers (`ShutdownProcessGroup`,
  `SortedEnvPairs`, `RemoteLaunchCommand`, `ProcessShutdownGrace`) → `spec/proc`;
  the caller-owned stdio pipe helper (`startProcessPipes`/`processPipes`, used
  only by kit's own process executor) stays in `sdk/kit/process.go`.
- `sdk/kit`'s `ShellQuote` → `spec/spec` (`spec.ShellQuote`). Every in-kit and
  in-deploykit caller repoints; the `sdk/kit` public `ShellQuote` is removed.

Repoints:

- `sdk/kit/deploy_executor_process.go` → `spec/proc.{SortedEnvPairs,
  RemoteLaunchCommand,ShutdownProcessGroup}`.
- `sdk/kit/{deploy_executor,deploy_executor_ssh,reexec_ssh,charly_install}.go`,
  `sdk/deploykit/{compiler_deps,localpkg,tasks_emit,write_labels,venue_builder}.go`
  → `spec.ShellQuote` (unused `sdk/kit` imports dropped from tasks_emit /
  write_labels).
- `sdk/vmshared/ssh_target.go` → thin `type SSHTarget = spec.SSHTarget` alias;
  `libvirt_uri.go` → `spec.CurrentUsername`; the `CurrentUsername` re-export
  drops from `exports.go`.
- `sdk/deploykit/deploy_chain.go` → `spec.ParseSSHTarget`.
- `sdk/{buildkit/privileged_runner,deploykit/{localpkg,venue_builder},vmshared/cloud_init_iso}.go`
  → `spec/proc` (proclifecycle temp-cleanup).

`go.mod`: `golang.org/x/crypto` is no longer imported by any sdk source (moved
to `spec/sshx`); the `require` is pruned by the post-spec-tag `go mod tidy`
(B2 retidy).

Verification: `go build/vet/test ./...` green across kit/deploykit/vmshared/
loaderkit/buildkit; `git grep 'sdk/(targetkit|sshx|proclifecycle|testkit)'` and
`git grep 'kit.ShellQuote'` both EMPTY.
