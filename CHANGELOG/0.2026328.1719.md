# 0.2026328.1719 — fix(deploykit): a command-only candy emits the scratch stage its commands mount

## Summary

`stageConsumed` counted only `copy:` / `data:` steps, but `EmitCmd` mounts `from=<candy>` for
**every** `command:` step. A candy whose plan is command-only (`layer-nodejs` / `layer-yay` in
`arch-builder`) therefore emitted no scratch stage, and BuildKit resolved the mount source as
`docker.io/library/<candy>:latest`:

```
#3 [internal] load metadata for docker.io/library/nodejs:latest
#3 ERROR: pull access denied ... insufficient_scope: authorization failed
```

Count a `command:` op as a stage consumer. The stage may be empty (a candy with no file sources);
`emitScratchStage` already handles that without a whole-project COPY.

Fixes opencharly/sdk#635; unblocks opencharly/charly#1270 and the `distro-cachyos` pin wave.
