## Summary

Remove the fail-open trailing-variadic `ctx` from the deploy-config family — the R5 root
fix PR #287 deferred. This is a breaking SDK contract change.

`ctx` is now a **required** parameter across: `LoadDeployConfig`, `SaveDeployConfig`,
`MutateDeployConfig`, `AcquireDeployConfigLock`, `SaveDeployState`, `CleanDeployEntry`,
`SaveVmDeployState`, `RemoveVmDeployEntry`, `LoadDeployConfigForRead|Write`,

`EncPlanFor`, `EncStatus`, `RemoveEncryptedVolumes`, `ResolveVmSshPort`,
`preflightMemberDNS`, and `loaderkit.hostDeployConfigDir`.

Every in-tree caller is migrated. An out-of-tree consumer that omits `ctx` now fails to
**compile** — the process-env path can never be silently reached.
