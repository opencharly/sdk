# 0.2026249.856 — feat(loaderkit): parse the unified from: name:tag deploy spelling (snapshot split)

## Summary

Phase 3 (the from: name:tag functional half) loader half: parse the unified deploy spelling.

- **`loaderkit/fleet_decode.go`**: `SetFleetCrossRef` splits a VM deploy's cross-ref on the LAST `:` into `From` + `FromSnapshot` (a VM entity name may not contain `:`, so the split is unambiguous); the new `splitVMSnapshotRef` helper is the ONE canonical splitter. pod/kubernetes IMAGE refs (ImageBacked — image tags legitimately contain `:`) are never split.
- **`loaderkit/node_tree.go`**: the MAPPING deploy form (`vm: {from: "base:golden"}`) decodes `from` into `From` via yaml directly (bypassing SetFleetCrossRef) — a post-decode normalization applies the same split, guarded to the non-ImageBacked arm; the already-split scalar form passes through untouched.
- Tests: splitter table (last-colon, no-tag, multi-colon), SetFleetCrossRef (vm splits, vm plain stays plain, pod image never splits), and **BuildFleetNode with the mapping deploy form** (asserting From+FromSnapshot both set — removing the normalization hunk fails it).
