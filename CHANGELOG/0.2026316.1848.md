# 0.2026316.1848 — refactor(workflowkit)!: delete the pipeline-kind machinery plugin-pipeline now owns

## Summary

**Leg 3 of unit 1's five-leg decomposition** (`TODO.md` 2.1, tracker `opencharly/spec#304` row 3). Leg 2 moved the `kind: pipeline` machinery into `plugin-pipeline`'s repo-local `workflowkit` package with a mechanical retype (`spec.Pipeline*` → `params.Pipeline*`, the kind-blind helpers called as `sdkworkflowkit.*`); this deletes the source copies so the machinery has ONE home.

Nothing here can name a pipeline body type any more.
