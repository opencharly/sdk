# 0.2026328.1805 — fix(deploykit): count PLUGIN verbs as scratch-stage consumers too

## Summary

The first fix for opencharly/sdk#635 counted only `op.Command`. A `plugin: command` step carries
its command in **`PluginInput`**, and every other plugin verb may render an act shell through the
same `EmitCmd` (`deploykit/tasks_render.go`'s `plugin` case), so it mounts `from=<candy>` too.
Count `op.Plugin != ""` as well; the regression test now covers both the literal `command:` and
the `plugin: command` form.

Fix-forward for opencharly/sdk#635; unblocks opencharly/charly#1270.
