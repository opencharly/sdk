# 0.2026267.2238 — fix(loaderkit): preserve PluginKinds at every diamond/multi-alias namespace path

## Summary of changes

Fix latent namespace-defects sharing ONE root cause — a **global pointer-identity guard** used where a namespace tree can be reached at MULTIPLE alias paths — exposed while making bed validation namespace-aware (the check-bed roster cutover). THREE fixes, all the same class:

1. **`loaderkit/materialize_wire.go`** — `capturePluginKindsSeen` / `restorePluginKindsSeen` used a global `seen map[*UnifiedFile]bool`. `spec.UnifiedFile.PluginKinds` is `json:"-"`, so this codec carries the maps across a reverse-leg `[]byte` payload. The same `*UnifiedFile` is mounted at multiple paths by design (a diamond import: `c` at `a.c` and `b.c`; a multi-alias mount: `arch` + `cachyos.arch`). The global guard recorded `PluginKinds` under only the FIRST path (map-order dependent); every later alias round-tripped with EMPTY `PluginKinds`, so a namespaced bed (`b.c.check-*`, `from: vm`) false-failed `references vm entity "vm" which is not defined`.
2. **`deploykit/resolved_project.go`** — `FillBoxPlans` carried the SAME global `visited map[*spec.Config]bool` guard: a shared config reached at multiple alias paths recorded box plans at only the first path. Same fix.
3. **`loaderkit/validate_check_beds.go`** — `ValidateIterateBed` read the `agent:` catalog from the merged ROOT, so a namespaced iterate bed (`charly.check-preflight-local`, `agent: claude` defined in its own namespace) false-failed `agent "claude" is not defined`. Extracted `validateIterateBedScoped` and changed the call site to read the catalog from the bed's OWNING scope (`BedScope`), the same scope fix as its `from:`-cross-ref sibling.

Fix shape (all three): replace the global visited/seen set with a **path-scoped ancestor stack** (`ancestors[x]=true; defer delete(ancestors,x)`) so EVERY alias path folds/round-trips while a genuine self-referential cycle still terminates.

Tests (all fail without their fix): `loaderkit/materialize_wire_diamond_test.go`, `deploykit/fill_box_plans_diamond_test.go`, and `loaderkit/validate_check_beds_namespace_test.go::TestValidateCheckBeds_NamespacedIterateAgentScoped`.

**Closes / relates to:** sibling opencharly/spec#155 (MERGED) fixed the same guard shape in `fillNamespacedTemplates`. Supports the check-bed roster cutover (spec#154 / sdk#281).

**Breaking change + rollback:** none (pure fixes). Rollback is a revert.
