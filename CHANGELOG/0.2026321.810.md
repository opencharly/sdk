# 0.2026321.810 — feat(auditkit): the append-only audit writer (D-AUDIT-1/3/4)

## Summary

**The first P06 leg that writes records rather than shapes.** `DESIGN.md` §20.1 names this area as the one whose subject was *"genuinely absent"* — charly logged, but kept no append-only record of an action and its outcome. The writer is now here, and the three D-AUDIT rows that shape it are enforced **structurally** rather than by careful calling.

| row | how the code satisfies it |
|---|---|
| **D-AUDIT-1** — exactly one record per act | `Append(act, event)` writes **one `O_EXCL` file per act**, named `<seq>-<actkey>.json`. A second append for the same act returns `ErrDuplicateAct`; `O_EXCL` means even a lost lock race **cannot** overwrite or duplicate a record |
| **D-AUDIT-3** — never holds a secret value | the writer accepts only `spec.AuditDetail`, whose `value?` is `*Redacted` — and `#Redacted` is `{redacted: true}`, a marker with **no field a value could occupy**. The guarantee is the type, not a validation |
| **D-AUDIT-4** — append-only | the exported surface is `Open`, `OpenDefault`, `(*Appender).{Append, Dir, List}` — **no update, delete or truncate exists**, and a test parses the package's own source to assert the exact set |

**The act id is the protocol's `call_id`, not a name invented here.** `DESIGN.cue:1330` gives every `#Request` a `#CallHeader` with `call_id!: #CallId` (`=~"^[0-9a-f]{32}$"`), and `audit_append` is a host method (`DESIGN.md:376`). So the leg-3 wiring is one line:

```go
a.Append(req.Header.CallId, req.AuditAppendInput.Event)
```

**No field is needed on `#AuditAppendInput` for it** — a second per-invocation identity beside the one the call header already mandates would be exactly the duplication that header exists to prevent.

The key is a **128-bit digest** of that id in the file name. That started at 8 bytes and was widened when the truncation was noticed: at 8, "two acts, one key" had a ~2³² birthday bound.

**Three assertions changed because of the contract fix this PR depends on** (`spec#345`, merged → `v0.2026320.2307`, where `value?` became `*Redacted`):

1. `Value: spec.Redacted{…}` → `Value: &spec.Redacted{…}`;
2. the decode assertion is nil-safe and must be non-nil;
3. **a new case in `TestRedactedIsAnEmptyMarker`**: a detail referencing no value must carry **no `value` key at all**. That assertion **fails at `.2238`** (where the key appeared as `{"redacted":false}`) and passes at `.2307` — so the pin bump is required, not incidental.

### Why the writer does not restate the schema's rules

`action?: #Word`, `at!: #Timestamp`, `identity!: #Ref` and the three word tables are `@go(-)` in the schema. Re-implementing their regexes or baking their word lists in Go would be the duplication `D-SCH-1`/`D-GEN-5` forbid, and it would drift. What this package checks is only what **no CUE pass can see**: the zero value of a required field, because a Go constructor never runs through the loader.
