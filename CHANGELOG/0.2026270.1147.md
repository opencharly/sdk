**Commit 2 — drop the version label + sha-key the cache view:**
- **The `ai.opencharly.version` OCI label is DROPPED entirely** from `generate.go`, `write_labels.go`, `vm_box_emit.go`; the image is identified by **`ai.opencharly.box`** (the boundary `ExtractMetadata` already uses). `ComputeEffectiveVersions` + `deploykit/effective_version.go` + its test DELETED. This resolves the prior empty-label regression: there is no version label to be empty.
- **Shared-cache safety restored, content-addressed.** `EnsureRepoDownloaded` now calls `DeriveRepoView(path, seams.MigrateCache)`: it derives a reshaped VIEW without ever mutating the pristine shared cache, under `lock.AcquireFileLock` + `copyTree` into a temp dir + a completeness marker + **atomic rename** (crash-safe), with the `markRepoAutoMigrating` re-entry guard (the documented 65 GB-RSS unbounded-recursion fix). The view path is **sha-based** — `reshapeViewPath` = `<cachePath>.view.<sha256(schemaIdentity + loaderIdentity)[:16]>` — so a schema/loader change re-keys, with **no `version:` in charly.yml** (the CalVer GIT tags are still used for ref resolution).
- Tests added: `loaderkit/reshape_view_test.go` — `TestReshapeViewIdentity_ReKeysOnIdentityChange` (fails without the identity-keyed path) and `TestDeriveRepoView_BuildsOnceReusesAndLeavesPristine` (marker short-circuits; pristine cache + no marker leak).
- `deploykit/render_parity_test.go`: the can-fail RIDER now perturbs `BakedMetadata.Status` (the version label it used to perturb is gone); the byte-golden updated.

**Commit 3 — the two review-driven tests:**
- `loaderkit/cache_identity_test.go` — `TestLoadedProjectCacheKey_ReKeysOnIdentityChange` (fails if the materialized-cache key stops re-keying on a spec/sdk identity change; restores the deleted `TestMaterializedCache_LoaderIdentityDriftReKeys` coverage via a `moduleIdentityFn` seam).
- `loaderkit/reshape_view_test.go` — `TestDeriveRepoView_ReentryGuardReturnsPristine` (re-enters `DeriveRepoView` from inside the reshape callback and asserts the guard returns the pristine cache without rebuilding/blocking — the 65 GB-RSS unbounded-recursion guard).
