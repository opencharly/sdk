# 0.2026293.417 — feat(buildkitdrive): mirror ghcr.io to a local registry (the base-input half)

## Summary

Adds the **input half** of the local-build bridge. `buildkitdrive` already bridges each built image's *output* into the run engine's store (`LoadExport`); nothing made a locally built image resolvable to **buildkitd** for the next stage's `FROM`. `DaemonOptions.RegistryMirror` renders:

```toml
[registry."ghcr.io"]
  mirrors = ["<local>"]

[registry."<local>"]
  http = true
```

## Why the exact shape matters (measured, not guessed)

Two other forms fail **silently** — the daemon ignores them and resolves upstream, which is why this took a while to attribute:

| config | result |
|---|---|
| `[registry."ghcr.io/opencharly"] mirrors = [...]` | resolve still goes to `https://ghcr.io/token...` → 403 |
| ...plus `[registry."127.0.0.1:5000"] http = true` | same — wrong key |
| `[registry."ghcr.io"] mirrors = [...]` + `[registry."127.0.0.1:5000"] http = true` | **resolves from the local registry, no ghcr query** |

- the mirror key is the registry **HOST**; a host+namespace key is ignored;
- a plain-HTTP mirror needs its own `http = true` stanza.

## How tested

Spike, rootless `buildkitd 0.34.0`, `registry:2` on `127.0.0.1:5000`, the image seeded as `127.0.0.1:5000/opencharly/spike-base:test`:

```console
$ buildctl build --frontend dockerfile.v0 ... --opt filename=Containerfile
#4 extracting sha256:1a000740... done
#5 [2/2] RUN echo MIRROR_RESOLVED_OK
build_rc=0
```

End-to-end through a **development** build of the consumer (plugin-build compiled against this sdk; `go build` from the charly worktree, not CalVer-stamped), building `arch` then `arch-builder`:

```console
# before
#2 ERROR: failed to authorize: ... 403 Forbidden
# after
#2 [internal] load metadata for ghcr.io/opencharly/arch:<calver>   DONE
```

with `arch:<calver>` present in `127.0.0.1:5000/opencharly/arch`.

Unit coverage: `TestDaemonConfig_CarriesTheRegistryMirror` asserts all three measured facts (host key present, host+namespace key absent, and the mirror host's own stanza carrying `http = true` — scoped to that stanza so a stray match elsewhere cannot satisfy it) and fails against the old rendering. `go test ./buildkitdrive/` ok; `go` and all four cross-compile jobs green.
