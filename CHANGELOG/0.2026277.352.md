# 0.2026277.352 — fix(kit): tolerate an absent substrate ledger on a first deploy into a fresh VM

## Summary

`AddCandyDeploymentVia` and `WriteDeployRecordVia` (`kit/install_ledger.go`) returned `exec.GetFile`'s error verbatim, so a **fresh guest** — where `~/.config/charly/charly.yml` legitimately does not exist yet — hard-failed the **first** `charly deploy add` into a newly created VM:

```
charly: error: command "deploy": deploy-dispatch add: deploy plugin: deploy-dispatch: venue ledger deploy record: ssh cat ~/.config/charly/charly.yml: exit status 1 (stderr: cat: /home/arch/.config/charly/charly.yml: No such file or directory)
```

The absence is not an error by this package's own design: `mutateRemoteLedger` documents that the substrate bytes "may be empty/absent" and builds a fresh document when they are, and the `mkdir -p ~/.config/charly && cat > …` write path creates the file. The guard returned **before** that tolerance was ever reached.

Both `Via` guards are narrowed to the not-found case. Every other read failure — permission denied, a broken channel, a substrate `charly.yml` that is not a mapping — still propagates, because treating those as "absent" would let the caller overwrite a file it could not read.

### The classifier is not new — it is unified

`kit` already carried the classifier as the unexported `isNotFound` (`kit/walk.go`), behind the same `if err != nil && !IsNotFound(err)` shape, serving the env.d managed-block read. This change **exports** it as `kit.IsNotFound` and makes it the one canonical classifier:

| Site | Before | After |
|---|---|---|
| `kit/walk.go` (2 reads) | `isNotFound` | `IsNotFound` |
| `kit/install_ledger.go` (2 guards) | `if err != nil { return err }` | `if err != nil && !IsNotFound(err) { return err }` |
| `deploykit/artifact_retrieve.go` (3 `optional:` sites) | local `isMissingArtifactFile` | `kit.IsNotFound` — local copy **deleted** |

`kit.IsNotFound` keeps every text form the deleted copy matched (`No such file or directory`, `cannot access`, `not found`) and adds the bare `no such file` form, so the artifact `optional:` behaviour is unchanged; and it uses `errors.Is(err, fs.ErrNotExist)` in place of `os.IsNotExist`, which is a strict superset (a *wrapped* not-found now counts too).
