# 0.2026269.700 — feat(kit): console terminal session, bounded flow, reference matching, auto-resume

## Summary

Adds the transport-agnostic **console automation** mechanism to `sdk/kit`: a
terminal-session engine, a bounded console flow (continuous OCR-until-condition
with if/then/else + case/switch + bounded while), perceptual **reference-screenshot
matching**, **auto-resume**, and the shared action layer the JetKVM and SPICE
verbs both call. It is the sibling of the existing `ConsoleWizard`.

New files:

- `kit/console_session.go` — `ConsoleSession`: run commands in an already-open
  terminal, reading each result by OCR; sudo password entry; LUKS/initramfs
  passphrase entry. Completion is an opaque **marker line** the shell echoes
  (`cmd; echo MARKER`), and the echoed input is stripped by that marker (not by a
  command prefix — a real shell echoes behind a prompt, so a prefix test would
  leave the echoed command in `Output` and let `Expect` pass vacuously).
- `kit/console_flow.go` — `ConsoleFlow`: a BOUNDED state machine. Each node
  OCR-polls continuously until a NAMED outcome appears (no guessed timeout),
  acts, then routes by the OBSERVED outcome. Named outcomes + `transitions` are
  if/then/else and case/switch; a back-edge is a while loop, bounded by
  `max_loops`/`max_steps` so a never-satisfied condition FAILS (R4).
- `kit/screen.go` — `ScreenSignature`/`ScreenHash`: a 64-bit difference hash
  (stdlib `image`, `image/png`, `image/jpeg`). An outcome can match by a
  reference screenshot instead of OCR.
- `kit/console_actions.go` — the shared action layer (`OpenTerminal`,
  `RunCommands`, `CloseTerminal`, `LUKSUnlock`, `RunBootOrder`, `RunConsoleFlow`).
- `kit/console.go` — `OCRBytes` now applies `ConsoleOCRScale=2`.

### RCA fixes forced by a live install (R1)

1. **OCR must upscale.** At 1x the GUI installer's form labels read
   `Usernane>`/`Confirn>`/`Hostnane>` (word-final `m>`→`n>`), stalling recipes
   anchored on `Username>`/`Confirm>`/`Hostname>`. At 2x they read correctly, and
   framebuffer anchors (`~`, `#`, `$`) survive (at 4x they do not — `~`→`R`).
   `ConsoleOCRScale=2`.
2. **A command typed blindly into a non-shell.** `run-command` now verifies a
   shell prompt first (`PromptAnchors`) and fails FAST otherwise. A flow exceeding
   the host's 2m per-step never-hang bound now stops CLEANLY on a `Deadline`.
3. **The echo trap in its `Expect` form** — the echoed input is stripped by its
   MARKER line, not a command prefix.
