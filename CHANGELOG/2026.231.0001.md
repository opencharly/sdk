## The typed StepContract (R3)

The three-form `StepContract` collapsed to the single typed `spec.StepContract`
(`Scope`/`Venue`/`Gate`/`Emits`); the string-form `capability.StepContract` is deleted.
`schema.go` re-exports the typed form and marshals it into `pb.StepContract` (Scope via
`Scope.String()`, Venue int32, Gate as the wire string) — the ~92 plugin call sites in
charly compile unchanged.

## The R5 deletions adopted

- **`LocalPkg`** — the deleted `CandyReader.LocalPkg`/`LocalPkgFormats` adapter methods in
  `deploykit/spec_candy_adapter.go` are removed (the deploykit `CandyModel` never declared
  them; zero callers; the IR already emits `LocalPkgInstallStep` from `Packaging()`).
- **`install_template`** — the removed `#Format`/`#Builder` field is adopted via the new
  `spec.FormatPhaseTemplate(format, phase, venue)` / `spec.BuilderPhaseTemplate(builder,
  phase, venue)` phase-cell accessors (no fallback arm): `deploykit/candy_steps.go` reads
  `phase.install.container`, `buildkit` re-exports the accessors, and the render tests
  assert the no-fallback behavior. The **retained** `LocalPkgDef.InstallTemplate`
  (`#LocalPkg.install_template`) is untouched.
- **`ResolveTunnelConfig`** — deleted with zero production callers; its sdk forwarder is
  removed, `TunnelConfigFromMetadata` stays.
- **`DeployTarget` → `EmitTarget`** — the sdk root re-export repointed; zero sdk users.
- **Casing sweep adopted** — `ForwardSshAgent` → `ForwardSSHAgent`
  (`kit/agent_forward.go`, `deploykit/deploy_state.go`), `VmSSH` → `VmSsh`
