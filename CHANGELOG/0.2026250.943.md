## Summary

Implements the **`config:` plan-step verb** emitter in `deploykit` (the schema contract landed in opencharly/spec#117; this PR consumes it).

- `tasks_emit.go`: new `SubstituteContent(content, vars, img)` — resolves ${NAME} refs in a config body against the candy's declared `var:` plus the image auto-exports (USER/UID/GID/HOME) at GENERATE time; unresolved refs are a hard error.
