# 0.2026329.1524 — fix(quadlet): emit the CDI device once when security.devices repeats it

## Summary

A GPU unit whose caller also lists `nvidia.com/gpu=all` in `security.devices` got the CDI device line
**twice**: `emitContainerSecurity` writes the implicit line for every GPU unit, then writes every
`Security.Devices` entry verbatim (opencharly/sdk#643; measured in
`~/.config/containers/systemd/charly-ollama-cdi.container`, lines 16–17).

The fix gives the device ONE spelling, `cdiDevice` (unexported), used by the implicit line and
skipped in the explicit list when it would repeat it. Non-CDI entries (`/dev/dri/renderD128`, …) are
unchanged, and the privileged branch is untouched (a privileged unit never carries the CDI device).
