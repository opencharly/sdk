# 0.2026260.1434 — fix(buildkit): compile for 32-bit ARM (Statfs_t.Bsize is int32 there)

## Summary of changes

Fixes **opencharly/sdk#262**: `sdk/buildkit` did not compile for 32-bit ARM, which blocked the entire module — and therefore charly and every plugin importing `sdk/buildkit` — from building for any 32-bit target.

- `buildkit/privileged_runner.go`: `checkFreeSpace` multiplied `int64(st.Bavail)` by `st.Bsize` directly. `syscall.Statfs_t.Bsize` is `int64` on 64-bit targets but **`int32` on 32-bit ones** (`linux/arm`, `linux/386`), so the mixed-type multiplication only fails off the 64-bit targets. The fix converts both operands; the product already promotes to `int64`, so the change is behaviour-preserving on 64-bit and is exactly what 32-bit needs. The cast carries `//nolint:unconvert` with the reason, because `unconvert` correctly sees it as a no-op on amd64 and cannot see the 32-bit target where it is required.
- **`.github/workflows/ci.yml` (NEW)**: this repo carried no CI of its own — only the two org-wide dispatchers — which is the mechanism that let #262 land (a 32-bit-only compile failure invisible until someone cross-compiled by hand). Adds **gofmt, `go vet`, `go test`** and a **cross-compile matrix over `linux/{amd64,arm64,arm,386}`** — the specific regression gate for this class, since a type-width difference like `Statfs_t.Bsize` is only observable off amd64. The lint step is not part of this workflow: the module's 29 lint findings are this cutover's own immediate-next work, tracked as `opencharly/sdk#264` (measured, with the per-linter breakdown), and that cutover adds the lint step as its acceptance gate. Everything the workflow DOES run passes on `main` today.
- `buildkit/privileged_runner_test.go`: adds `TestFreeSpaceArithmeticIs32BitSafe`. A test cannot observe its own package's compile failure, so the guard pins the invariant from the source side — the only free-space multiplication must convert both operands — catching a refactor that reintroduces the mixed-type form. The existing behavioural coverage (`TestCheckFreeSpace`) is unchanged.

**Closes / relates to:** `Closes opencharly/sdk#262`.

**Breaking change + rollback:** `none` — the change is a no-op on every 64-bit target and only enables 32-bit compilation. Revert the merge to roll back.
