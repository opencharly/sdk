# 0.2026328.2210 — docs(skill): a command or plugin step consumes the candy's scratch stage

## Summary

Docs-only: `generate-source` (the skill for the Containerfile render) now documents the
scratch-stage consumer rule behind opencharly/sdk#635 / #636 / #637. `EmitCmd` emits
`--mount=type=bind,from=<candy>,source=/,target=/ctx` for a literal `command:` **and** for a plugin
verb whose provider renders an act shell — `plugin: command` carries its command in `PluginInput`,
not `Command`. `stageConsumed` therefore counts a `command:` op and a plugin op, in addition to the
`copy:` / `data:` consumers. A command-only candy otherwise mounts a stage that was never emitted,
and BuildKit resolves the mount source as `docker.io/library/<candy>:latest` — the arch-builder
failure in opencharly/charly#1270.

`references/multistage-and-intermediates.md` (the rule, under "Scratch Context Stage").
