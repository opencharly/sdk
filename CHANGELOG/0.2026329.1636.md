# 0.2026329.1636 — docs(deploykit): keep-id carries the CDI device; only the spec's file mounts cannot

## Summary

The `carriesCDIDevice` comment in `deploykit/quadlet.go` still says a unit that carries the CDI GPU
device **cannot run under keep-id**, citing #81. That stopped being true when #640 made a
bind-mounting unit ride keep-id and plugin-deploy-pod#97 made the caller point the engine at a
**devices-only** CDI spec: what keep-id cannot apply is the spec's **file mounts**, never the
**device**.

Comment only — no behaviour change. The duplicate-`AddDevice` fix landed separately in #645.
