# 0.2026252.819 — feat(checkkit): the shared check-drive pieces (grammar, verb resolver, ADE grader)

## Summary
New `sdk/checkkit` package: the SHARED check-drive pieces every check-driving plugin consumes — `PlanGrammar` (the do-mode/context grammar, ported from the core hostPlanGrammar), `VerbResolver` (the out-of-process verb dispatch over the plugin's single dial, with the venue-descriptor threading), the `CheckEnv` snapshot, and the `AdeGrader` contract. One home (R3): these were plugin-local in plugin-check; they belong in the SDK so any plugin drives the org's check machinery identically.
