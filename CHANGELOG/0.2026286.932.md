# 0.2026286.932 — test(deploykit): control TestCandyProjectDir's premise instead of asserting an absolute (sdk#366)

## Summary

`TestCandyProjectDir`'s last case asserted an **absolute** outcome for a **relative** property:

```go
	// No enclosing project.
	orphan := t.TempDir()
	writeProjectFile(t, orphan, spec.UnifiedFileName, "orphan:\n")
	if got := candyProjectDir(filepath.Join(orphan, spec.UnifiedFileName)); got != "" {
		t.Errorf("candyProjectDir orphan = %q, want \"\"", got)
	}
```

`candyProjectDir` walks from the manifest's directory **to the filesystem root**, and `t.TempDir()` lives in the host's temp root — so `""` holds only when *nothing* in that ancestry is a project. A stray `charly.yml` anywhere above the temp dir (a leftover `/tmp/charly.yml`, say) makes the walk **correctly** return its directory, and the test then failed on a host where the code was behaving correctly.

Reproduced exactly before the change — including line 834 and the message the row reports:

```console
$ printf 'discover:\n  - path: candy\n' > /tmp/charly.yml
$ go test ./deploykit/ -run TestCandyProjectDir -count=1
--- FAIL: TestCandyProjectDir (0.00s)
    localpkg_test.go:834: candyProjectDir orphan = "/tmp", want ""
FAIL
exit=1
```

**One detail that decides whether this reproduces at all**, measured while setting it up: `t.TempDir()` resolves under the host's temp root, and **Go propagates `GOTMPDIR` to the test binary's temp dir**. With `GOTMPDIR=~/.cache/go-tmp` set, `t.TempDir()` is `~/.cache/go-tmp/Test…/001` and `/tmp/charly.yml` is not an ancestor — the stray file must be placed in *that* ancestry, or `GOTMPDIR` left unset. The row's own report matches the `/tmp` shape, which is what a plain `go test` gives.

**The fix controls the premise instead of the environment:** when the walk returns a directory, it must be an **ancestor** of the manifest's directory **and** carry the project file; the project-free case keeps the exact `""` form. The deterministic nearest-ancestor behaviour remains covered by the two fixture cases above it, which the host cannot perturb.
