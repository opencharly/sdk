# 0.2026246.613 — feat(deploykit): VM box image emitter + reader — EmitVmBox / VmCapabilitiesFromLabels

## Summary

Task 2 (sdk half) of the VM-box cutover (plan/vm-from-box-layering.md §2.1: "a VM box is an OCI image whose labels carry the VM metadata contract and whose layers carry the disk artifact"). The spec half (spec PR #90, MERGED) landed `spec.VmBoxMetadata` + `VmBoxSource` + `LabelVmBox = "ai.opencharly.vm.box"` + the `VmBoxLabelMap` completeness gate; this PR lands the sdk emitter/reader that bakes and reads that contract on real box images.

Changes (4 files, +275):
- **`go.mod` / `go.sum`** — bump `github.com/opencharly/spec` `v0.2026243.707` → `v0.2026246.554` (the tag-on-merge tag of spec PR #90's merge commit; carries VmBoxMetadata + LabelVmBox + VmBoxLabelMap). `go mod tidy` clean.
- **`deploykit/vm_box_emit.go`** (new) — the VM box image emitter + reader:
  - `EmitVmBox(engine, ref, meta, diskPath)`: stages a temp Containerfile (`FROM scratch`, `COPY <disk> /disk.qcow2`, `LABEL ai.opencharly.vm.box=<whole-struct JSON>` + `ai.opencharly.version=<meta.Version>` + `ai.opencharly.description=<JSON>`), runs `podman build -t <ref>` with the disk's own directory as the build context (the disk is never copied), removes the temp Containerfile. The disk COPY is the layer; the labels are the contract. Engine binary via `container.EngineBinary`; label values quoted with `spec/shellquote.ShellQuote` exactly like the pod-side WriteLabels emitter.
  - `VmCapabilitiesFromLabels(engine, ref)`: `container.InspectLabels` (the same inspect seam `CapabilitiesFromLabels`→`ExtractMetadata` uses) → reads `ai.opencharly.vm.box` → unmarshal into `*spec.VmBoxMetadata`. Mirrors the `ErrImageNotLocal` wrap when the image is absent locally.
- **`deploykit/vm_box_emit_test.go`** (new):
  - `TestVmBoxMetadataLabelRoundTrip` — marshal a populated VmBoxMetadata → unmarshal → DeepEqual (the label contract round-trips through the sdk's pinned spec).
  - `TestVmBoxLabelCompleteness` — `spec.CheckVmBoxLabelCompleteness()` nil (every field covered by the label map).
  - `TestVmBoxEmitReadBackRoundTrip` — LIVE integration test (podman IS available on this host): emits a 1-byte fixture "disk" with a fully-populated metadata contract into local podman storage, reads it back, asserts DeepEqual equality, and asserts the image has exactly ONE layer (the disk COPY). Skips with `t.Skip` when podman is absent.
