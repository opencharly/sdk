head added a `check-sdk-shell-hook:` bed, and this class forbids one.** The rulebook says so in the row
itself — `.dsh/skills/check/references/beds-and-r10.md:495`:

> *"Run the repo's OWN committed module CI … GREEN on the PR head — the module suite **IS** the gate,
> because **no bed CAN exist** (a bed that cannot fail on the change proves nothing)."*
>
> *"Explicitly NOT required: A `charly check run` bed in the module repo — **none can exist there**."*

> *"A change whose behaviour is observable only at a CONSUMER's live boundary **names the consumer PR**
> running that bed — the bed rides the consumer change (producer→consumer order, B6), **never the library

**So `charly.yml` and the `.gitignore` line that existed only to ignore its output are removed.** Both were
added by this PR, so this is a deletion rather than a revert, and it is a real tree change rather than a
