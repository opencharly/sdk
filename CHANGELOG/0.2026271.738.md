# 0.2026271.738 — fix(loaderkit)!: warn on candy content divergence, not on a byte-identical re-tag

## Summary

Fix the sole candy-version arbiter — `loaderkit.PickCandyVersion` — so it **no longer warns on a re-tag of byte-identical candy content**. This is the root fix for the `charly#716` zero-warnings block: the warning stream from this predicate was dominated by hub repos whose `charly.yml` bytes are identical across two tags.

### Root cause (R1)

`PickCandyVersion` arbitrated one bare ref's candidate materializations by their **source git tag** and emitted an advisory whenever two candidates carried **different tags** — with no regard to whether the candy's *content* differed. A hub repo re-tags an UNCHANGED candy far more often than it changes that candy (a sibling landing mints a new tag; `tag-on-merge` re-mints it every merge), so one skewing hub emits one advisory per affected bare ref.

**Measured** on the local repo cache (271 repos with ≥2 tag materializations): **86 carry a byte-identical root `charly.yml` across their tags** — e.g. `layer-dev-tools v2026.235.2056 ≡ v2026.239.1624` (`diff -q` → identical), `layer-nodejs`, `layer-supervisord`, `layer-rust`, `layer-socat`, `layer-claude-code`, `layer-desktop-fonts`.

### Fix

The advisory now fires **only when the candidates' content genuinely differs** (or cannot be determined). Identity is, in order:

1. the **sha256 of the candy's own `charly.yml`** at its fetched materialization directory — the authored source, the ground truth for "is this the same candy?"; else
2. a **canonical JSON digest of the resolved scan with `Model.SourceDir` excluded** — the per-`(repo, tag)` cache path embeds the tag, so it must never count as content.

The newest tag still wins **unconditionally** (for identical bytes the choice is moot). The conservative direction is preserved: a candidate whose content cannot be determined makes the set "not identical", so an **unprovable pair still warns**. The advisory text gains `with differing content` so the surviving line is self-describing.
