# 2026.224.0404 — bake box-authored OCI ENTRYPOINT/CMD; quadlet HostName= parity

The sdk half of the AgentTeams manager crash-loop fix (spec → sdk → main):
consumes the new opt-in `entrypoint:`/`cmd:` box wire fields (spec
v0.2026224.403) and emits them into the image's OCI config, so a box whose
children are spawned DIRECTLY from its baked OCI config (no charly deploy in
the loop to inject the init command) can bake the command they run.

- **`deploykit/generate.go`** (Containerfile emitter): writes `ENTRYPOINT <json>`
  when the box declares an entrypoint and `CMD <json>` when it declares a cmd —
  both OPT-IN and empty by default (a normal charly image ships no baked
  command; the deploy-time init injects it). `cmd: []` clears a base image's
  inherited default command; a declared entrypoint with no `cmd` emits an
  auto-`CMD []` so the entrypoint runs bare instead of double-launching the base
  image's default command.
- **`deploykit/quadlet.go`**: the quadlet `[Container]` key is `HostName=`
  (camelCase) — the lowercase `Hostname=` is NOT a supported key and quadlet
  SKIPS the entire unit over it (`systemctl --user start` fails exit 5 "Unit not
  found"). Emission now writes the valid `HostName=` key (mapped by quadlet to
  podman's `--hostname`), giving the in-container hostname = the charly-network
  DNS name — parity with the direct-run `--hostname <name>` argv the main-repo
  pod plugin emits. The golden test pins the emitted unit byte-exact.
- **`buildkit/config_resolve.go`** + **`deploykit/resolved_project.go`** +
  **`deploykit/spec_resolved_box_adapter.go`**: project the box-authored
  `Entrypoint`/`Cmd` through the resolved-box forms so the plugin-build resolve
  leg re-emits them without the live candy graph.
- **`deploykit/oci_packaging_test.go`**: emitted-as-OCI-ENTRYPOINT/CMD,
  declared-empty-cmd-clears-base-cmd, and the blast-radius guard — a default box
  ships NO baked command. All fail without the change.
