# 0.2026256.1220 — feat(packagekit): package the shared plugin host + symlinks (hard cutover)

## Summary

**Hard cutover** of the packaging plugin layout (opencharly/sdk#256). `sdk/packagekit` now
supports exactly ONE layout:

- the shared `charly-lib` multi-call host is staged **once** at
  `/usr/lib/charly/plugins/charly-lib`;
- every variant plugin is a `plugin-<word>` **symlink** to it (nFPM `TypeSymlink`);
- a **regular-file** plugin entry is a **hard error**, as is a plugin present without the host —
  the per-plugin binary layout (one re-linked copy of the shared SDK/spec closure per plugin,
  ~21 MB apiece) is retired, never silently shipped.

The distro repos that still pass per-plugin binaries migrate to the shared host in their own
packaging PRs — **each named**: `charly-arch#5`, `charly-fedora#3`, `charly-debian#3`,
`charly-ubuntu#4`, `charly-alpine#1`, `charly-openwrt#1`.
