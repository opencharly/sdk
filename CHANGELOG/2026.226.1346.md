# 2026.226.1346 — admit plan-bearing pure-composition candies to the resolved order

The sdk half of the AgentTeams snapshot-tool cutover (main-repo Unit 3): a
pure-composition candy (one whose only body is a `candy:` composition list —
no env, ports, services, or install files) that carries a `plan:` was dropped
from the resolved install order, so its plan never baked into the
`ai.opencharly.description` OCI label. ADE requires every candy's plan to be
runnable acceptance — a plan-bearing composing candy must enter the closure
even though it contributes nothing to the build.

- **`deploykit/graph.go`** (`layerEntersOrder`): one shared predicate deciding
  admission — `HasContent() || len(PlanSteps()) > 0` — used by both
  `ExpandCandy` and `addTransitive` (R3: the two sites previously carried
  duplicated inline copies).

  Admission is keyed to the PLAN alone. A non-empty description is
  deliberately NOT a term: ADE makes a description mandatory on every candy,
  so admitting on it would admit every composing candy unconditionally,
  making the predicate equivalent to "always true" for local candies — a far
  wider behaviour than the plan-baking this exists for. Measured against the
  current tree: 23 composing candies, 9 pure-composition-with-plan, and zero
  that a description term would admit which the plan term does not.
- **`deploykit/graph.go`** (`ExpandCandy` doc comment): swept — it still
  asserted the pre-change rule ("candies without content are omitted") six
  lines above the changed line.
- **`deploykit/graph_shim_relocated_test.go`**:
  `TestComposingCandyWithPlanEntersOrder` (a pure-composition candy with a
  plan enters) and `TestComposingCandyWithOnlyDescriptionIsOmitted` (one
  carrying only a description does not). The second exists because the
  description term was otherwise unfalsifiable: removing it from the
  predicate left the whole suite green, since every other fixture that
  exercises admission also carries a plan.

Affected candies: 9 pure-composition candies carry plans and had them silently
dropped from the description label — `agent-forwarding`, `agentteams`,
`agentteams-snapshot`, `hermes-full`, `openclaw-full`, `openclaw-full-ml`,
`selkies-desktop`, `selkies-kde-desktop`, `sway-desktop`.

includes.
